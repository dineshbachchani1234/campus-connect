# High fidelity user testing

The rubric asks for 3 to 5 participants, with demographics, tasks, context, observations, session recordings and analysis.

Keep recordings out of this public repository. Store them in the team's shared drive and link them from the report.

## Files to add here

- `test-plan.md`: intro script, tasks, success criteria, roles (adapt from our low fidelity plan)
- `participants.md`: one row per participant, with no real names (P1 to P5), program, commuter or not, device, date, location
- `notes/P1.md` ... `notes/P5.md`: observations, quotes, time on task, errors
- `analysis.md`: patterns across sessions and the changes we made

## Tasks

1. You only come to campus on Tuesdays and Wednesdays. Find something on one of your campus days that you could join, and join it.
2. You just went to that study session and enjoyed it. Set it up so it happens every week, then find where your regular groups live.
3. (If time allows) Nothing fits your schedule this week. Create your own small plan.

## Before each session

- Reset the app (Profile, Reset all demo data)
- Start screen recording with consent
- Read the intro script

## Task 2 note

Testers cannot wait for a real meetup to end. The facilitator triggers the "Make this weekly?" prompt from the group chat or the demo panel when the participant says they have "attended" the plan.
